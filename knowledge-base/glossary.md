# Glossary

| Term | Meaning |
|------|---------|
| AURN | Automatic Urban and Rural Network — main UK near real-time monitoring network (hourly) |
| UKEAP | UK Eutrophying and Acidifying Atmospheric Pollutants network — long-term rural trends (e.g. Rural NO2 Network, Acid Gas & Aerosol Network) |
| DAQI | Daily Air Quality Index — group of PM2.5, PM10, NO2, O3, SO2 |
| Air Quality Standards Regulations 2010 | Regulatory group: DAQI pollutants + NO, NOx as NO2, CO |
| PM2.5 / PM10 | Fine particulate matter / particulate matter |
| NO2 / NOx / NO | Nitrogen dioxide / nitrogen oxides as NO2 / nitric oxide |
| O3 / SO2 / CO | Ozone / sulphur dioxide / carbon monoxide |
| Data capture | % of possible measurements actually recorded in the period (0–100%) |
| Exceedance | A day/hour when a pollutant goes above its limit value |
| Site type | Urban Background, Urban Traffic, Rural Background, Urban Industrial |
| Near real-time data | Automatically measured and published every hour (AURN) |
| Verified data | Data that has passed QA; current year verified to 30 June |
| Long format (CSV) | Data stacked vertically — one row per measurement |
| Toggletip | The (i) button that reveals an explanation |
| Defra | Department for Environment, Food & Rural Affairs (service owner) |
